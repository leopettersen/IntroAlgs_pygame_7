# Documentacao

Esta pasta concentra documentos de planejamento e apoio ao projeto.

## Arquivos

- `proposta.MD`: proposta inicial do jogo para preenchimento do grupo.
- `README.md`: registro do processo de decisões e mudanças no projeto.

## Decisões / Mudanças de escopo:
- Escolha de imagens para nave e meteoros, optamos por imagens disponíveis gratuitamente na internet.
- Tipo de pontuação: decidimos entre a pontuação por segundo e pontuação por meteoro que passa na tela, optamos pela pontuação por meteoro
- Mudança nos meteoros: meteoros apenas desapareciam, agora tem uma animação de explosão.
- POO: durante o processo adaptamos nosso código para POO.
- Nave com tiros: inicialmente a nave não atirava, mas uma mudança foi feita para que fosse possível destruir meteoros com tiros da nave
